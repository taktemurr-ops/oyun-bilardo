# Bilardo (oyun-bilardo)

Masa Oyunları merkez uygulamasındaki bilardo oyunu. Istakayı geri çekip bırakarak topları cebe sokarsın; beyaz topu sokmak fauldür.

- 33 dil, kampanya + günlük + zen + sonsuz + zamana karşı modları
- Seviyeler `studio_core` seviye planlayıcısıyla üretilir; aynı tohum aynı masayı verir
- Testler: `flutter test` (bot kampanya seviyelerini bitirir, kayıt yeniden oynatılır)

Kullanım: `import 'package:oyun_bilardo/oyun_bilardo.dart';` ve `bilardoConfig`.
